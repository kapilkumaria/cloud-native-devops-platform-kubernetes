# Cloud-Native DevOps Platform - Kubernetes Manifests Repository

This repository contains Kubernetes and GitOps manifests for the Cloud-Native DevOps Platform.

## Purpose

This repository represents the platform deployment layer. It stores declarative Kubernetes manifests and ArgoCD application definitions.

## Components

- Frontend Kubernetes manifests
- Backend Kubernetes manifests
- PostgreSQL Kubernetes manifests
- ArgoCD Application definitions
- Monitoring manifests structure
- Validation documentation
